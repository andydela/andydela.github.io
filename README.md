# Andy Kobby Debrah — CV

A responsive, static CV covering data analysis, cybersecurity foundations, research, education and work experience.

## Files

- `index.html`: the complete CV, including styles and the print/save-PDF button.
- `.nojekyll`: serves the files directly without Jekyll processing.

No installation or build step is required. Open `index.html` to review the CV locally.

## Publish with GitHub Pages

1. On the `andydela` GitHub account, create a public repository named `andydela.github.io`. If it already exists, review its contents before uploading or replacing files.
2. Upload these files into the repository root on the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/ (root)**, then save.
6. Wait for the deployment to finish and confirm the address shown in GitHub Pages settings.

The intended address is `https://andydela.github.io/`. Preparing these files does not itself publish that address.

## Updating the CV

Edit `index.html` and commit to `main`. GitHub Pages will publish the updated page. Keep qualifications, course completion and employment dates accurate.

Setup reference: [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
